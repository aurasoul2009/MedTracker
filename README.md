# MedTrack

A focused medicine management app built with Node.js, Express, MongoDB, and a premium vanilla frontend.

## What It Does

- Add and store medicine schedules
- Enter reminder times with a 12-hour picker
- View medicines in a clean responsive dashboard
- Mark doses as taken
- Review history with `taken` and `missed` states
- Switch between dark and light mode with saved preference

## Project Structure

```text
controllers/
models/
public/
routes/
server.js
```

## Environment Variables

Create a `.env` file in the root using `.env.example`.

## Run

```bash
npm install
npm start
```

Open [http://localhost:5000](http://localhost:5000)
